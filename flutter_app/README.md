# FanZone — Flutter Mobile App (ХК «Сибирь»)

Кроссплатформенный дубль приложения FanZone для iOS, Android, Windows и Web.

---

## 🚀 Как запустить и тестировать прямо на Windows

### 1. Запустите бэкенд
Убедитесь, что бэкенд и базы данных запущены:
```powershell
cd E:\prilox\backend
docker-compose up -d
npm run dev
```

---

### 2. Запуск приложения на Windows

#### Вариант А: Запуск в браузере (Chrome) с экраном смартфона:
Если у вас установлен Flutter SDK:
```powershell
cd E:\prilox\flutter_app
flutter pub get
flutter run -d chrome
```
*В Chrome нажмите **F12** → нажмите иконку **мобильного устройства (Toggle Device Toolbar)** → выберите **iPhone 14 / iPhone 15 Pro** — и вы получите 100% экран айфона прямо на Windows!*

#### Вариант Б: Запуск в Android Studio (Эмулятор смартфона):
```powershell
cd E:\prilox\flutter_app
flutter run -d android
```
Эмулятор Android отображает полноценный виртуальный телефон со всеми функциями.

## 🌐 Настройка подключения к бэкенду (API Host)

В приложении на экране входа в правом верхнем углу есть иконка **шестерёнки (⚙️)**:
- **Для Web / Chrome / Windows:** `localhost:3000`
- **Для Android Эмулятора:** `10.0.2.2:3000` *(эмулятор обращается к вашему ПК через этот IP)*
- **Для физического телефона по Wi-Fi:** `192.168.x.x:3000` *(локальный IP вашего компьютера)*

## 📱 Роли и функционал в приложении

### 1. Болельщик (USER)
- **Главная:** Героическая карточка ближайшего матча с обратным отсчётом и статусом фан-сектора, список ближайших матчей.
- **Матчи:** Фильтры (Ближайшие, Прошедшие, Домашние, Выездные), детальная страница с индикатором заполняемости.
- **Бронирование:** Подача заявки на билет в фан-сектор.
- **Мои брони:** Вкладки "Предстоящие" и "История", статусы заявок (На рассмотрении, Подтверждено, Отклонено), отмена брони.
- **Электронный билет:** Отображение билета с динамическим QR-кодом для входа.
- **Профиль:** Статистика посещений (посещено, пропущено, подтверждено), социальные сети, история матчей.

### 2. Ответственный (BOOKING_MANAGER)
- **Заявки:** Списки Новые / Подтверждённые / Отклонённые с кнопками подтверждения и отклонения в 1 клик.
- **Профиль болельщика:** Просмотр статистики надежности болельщика перед подтверждением заявки.
- **Участники:** Выбор матча и отметка посещаемости болельщиков ("Посетил" / "Не явился").
- **Сканер билетов:** Проверка QR-токена билета на сервере и отметка посещения по QR.

### 3. Администратор (ADMIN)
- **Управление матчами:** Просмотр всех матчей, кнопка создания нового матча (выбор команд, арены, даты, вместимости сектора), удаление матчей.
- **Управление людьми:** Поиск любого болельщика по нику или имени, изменение роли (Болельщик ↔ Ответственный ↔ Админ).
- **Статистика клуба:** Общие цифры (всего людей, заявок, посещаемость) + посещаемость по каждому матчу.
